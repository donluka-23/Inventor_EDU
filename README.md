# INVENTOR EDU — independent execution-controlled starter

**მიზანი:** ქართულენოვანი სასწავლო ელექტრონიკის პლატფორმა, რომელიც დამწყებს საშუალებას მისცემს 2D გარემოში დააკავშიროს მხარდაჭერილი კომპონენტები და მიიღოს სანდო, მკაფიოდ შეზღუდული ელექტრული/პინების შემოწმება და გასაგები განმარტება.

**აქ არ არის აპლიკაცია.** ეს პაკეტი შეიცავს პროცესის მართვას, კვლევითი/არქიტექტურული გადაწყვეტილებების ცალკე მიღების წესს, Codex-ის შემსრულებლის ინსტრუქციებსა და ანგარიშის ფორმატს.

## სამუშაო მოდელი

1. **Research/architecture (ამ ჩატში):** განვიხილავთ სამეცნიერო საფუძვლებს, ტექნოლოგიებს, ლიცენზიებს, საინჟინრო მოდელებს, ალტერნატივებს და მიღების კრიტერიუმებს.
2. **Approval (მომხმარებელი):** ირჩევს/ამტკიცებს გადაწყვეტილებას და კონკრეტულ ამოცანას. პროექტში ფიქსირდება მიღებული ADR და გაყინული დავალება.
3. **Execution (Codex):** კითხულობს მითითებულ ფაილებს, ასრულებს მხოლოდ ერთ ავტორიზებულ ამოცანას და უშვებს მოთხოვნილ ტესტებს. არ იღებს ახალ არქიტექტურულ გადაწყვეტილებებს.
4. **Handoff:** ქმნის `reports/<TASK_ID>-REPORT.md`-ს. მომხმარებელი ტვირთავს/აკოპირებს ანგარიშს ამ არქიტექტურულ ჩატში.
5. **Review:** აქ განვიხილავთ, მიღებულია თუ არა შესრულება, საჭიროა თუ არა შესწორება და რა იქნება შემდეგი ზუსტი გეგმა.

## ინსტალაცია

გახსენით არქივი ახალ ცარიელ რეპოზიტორიის root-ში, ისე, რომ `AGENTS.md` root-ში იყოს. შემდეგ სურვილისამებრ გაუშვით `python scripts/preflight.py` — ეს მხოლოდ დოკუმენტების სტრუქტურას ამოწმებს და არა პროდუქტის მუშაობას. ახალი Git რეპოზიტორიის ინიციალიზაცია ცალკე შესრულებადი მოქმედებაა და არ ნიშნავს ტექნიკური არქიტექტურის დამტკიცებას.

## Codex-ის პირველი, სრულიად შეზღუდული ამოცანა

# Use approved artifacts only
1. Read `AGENTS.md`, the frozen task plan, `docs/OSS_POLICY.md` and `governance/OSS_REGISTER.csv`.
2. Confirm artifact identity, pinned version, usage rights, distribution conditions and registry APPROVED status **provided by owner-approved architecture plan**.
3. Do not choose, add, replace or approve external code, models, media, databases or assets independently.
4. If the declared artifact conflicts with actual license, has unresolved transitive obligations or mismatched model fidelity, STOP; record evidence and BLOCKED report. No silent substitution.
5. Log exactly what was installed or imported; if NONE, state NONE.

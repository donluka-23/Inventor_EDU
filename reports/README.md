# Codex handoff reports

Each authorized task MUST produce exactly one self-contained Markdown report at `reports/<TASK_ID>-REPORT.md`, modeled on `REPORT_TEMPLATE.md`. A failure or BLOCKED session still requires a report. The owner must attach/upload or paste the report back into the architecture/research conversation; no automatic cross-chat delivery exists. Include exact terminal results, changed files, acceptance status and architecture blockers.

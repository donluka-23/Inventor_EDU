# Roadmap — owner/architect controlled stage gates

| Gate | Intended outcome | Required external approval/evidence |
| --- | --- | --- |
| P0 | Repo governance boot verified | Authorized BOOT-001 execution report reviewed by owner |
| P1 | Standards-grounded electrical data contract | External research + owner-approved ADR + frozen task plan; then Codex fixture implementation |
| P2 | Headless connectivity and bounded verification | Approved contract, deterministic PASS/FAIL/UNKNOWN oracles |
| P3 | 2D editor to canonical-net integration | Accepted headless engine plus approved UI contract |
| P4 | One bounded physical calculation, if justified | Model applicability/accuracy, independent oracle, license clearance and owner authorization |
| P5 | Georgian novice explanation and lesson UX | Accepted finding-to-learning contract and observed user test |
| P6 | Demo readiness | Reproducible live scenario, scope limits, source-backed checks |

**This roadmap is not a Codex task list.** Every stage requires one or more separately authorized bounded execution plans authored outside Codex. Codex must never create its own next phase or turn a future intention into an implemented feature.
